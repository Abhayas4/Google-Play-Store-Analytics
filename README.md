# Google Play Store Analytics | Power BI

## Project Overview
An end-to-end data analytics project focused on exploring and analyzing Google Play Store applications using Microsoft Power BI. The project examines app distribution, downloads, ratings, reviews, pricing models, and user engagement to identify patterns and generate meaningful insights.

## Objectives
- Analyze the distribution of applications across categories.
- Evaluate app ratings and review sentiment.
- Explore download trends across categories and app types.
- Compare free and paid applications.
- Understand user engagement through reviews and ratings.
- Identify patterns and trends that can support data-driven decisions.

## Tools & Technologies
- **Power BI** – Interactive dashboards and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures, KPIs, and analytical metrics.
- **Excel / CSV** – Dataset preparation and exploration.

## Dashboard Structure

The dashboard consists of five analytical pages:

1. **Overview** – High-level KPIs and an overall view of the Google Play Store app ecosystem.
2. **Category Analysis** – Category-wise comparison of applications, ratings, downloads, and review sentiment.
3. **Installs Analysis** – Exploration of application downloads and installation patterns.
4. **Engagement Analysis** – Analysis of ratings, reviews, and user engagement patterns.
5. **Insights** – A consolidated presentation of key findings from the analytical pages.

## Key Features
- Interactive dashboard with multiple analytical views.
- KPI cards for important performance metrics.
- Category-wise comparisons.
- Download and installation analysis.
- Review sentiment analysis.
- Dynamic filtering and visual exploration.

## Project Files
- `.pbix` – Power BI project file.
- `PLaystore Analytics` – Dashboard page previews.
- `Dataset/` – Source datasets, where redistribution is permitted.

## How to Explore
1. Download the Power BI `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Interact with the dashboard using available filters and visualizations.
